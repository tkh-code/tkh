# いろ あて クイズ！ — 子供向けYouTube動画

`make_video.py` が、ナレーション、BGM、効果音、アニメーションをすべてオフラインで生成し、
1920×1080 / 30fps の MP4（約1分55秒）とサムネイル（1280×720）を書き出します。

## 人気動画から取り入れた要素

| 人気チャンネルの特徴 (Cocomelon, Pinkfong など) | この動画での使い方 |
| --- | --- |
| はっきりした原色、コントラストの強い絵 | 7色それぞれを背景色にし、太い輪郭線で描く |
| 毎回同じ流れのくり返し | 「これは なにいろ かな？」→ 3・2・1 → 答え → 英語、を7回くり返す |
| 子供が答えられる「間」 | 答えの前に3秒のカウントダウン |
| 顔のあるキャラクター | 口が声に合わせて動くマスコット「ぴよちゃん」、顔のついたくだもの |
| 日本語と英語のバイリンガル | 「えいごで いうと、レッド！」 |
| おさらいで記憶に残す | 最後に7色を順に読み上げる |
| 刺激の強すぎない編集 | 1〜3秒ごとのカットはせず、1シーン約12秒 |

## 生成方法

```sh
apt-get install open-jtalk open-jtalk-mecab-naist-jdic fonts-mplus ffmpeg
pip install pycairo numpy
# HTS voice "Mei" は MMDAgent_Example-1.8.zip の Voice/mei/ に入っています
MEI_VOICE=/path/to/mei_happy.htsvoice python3 make_video.py out
```

`STILLS=3,9.5` を付けると、動画の代わりにその秒数の静止画を書き出します（確認用）。

## YouTube に投稿するとき

- **視聴者**: 「はい、子ども向けです」を選ぶ（COPPA と YouTube の規約で必須）。
- **タイトル例**: いろ あて クイズ！くだもので いろを おぼえよう🍎 | 赤ちゃん・幼児向け 知育アニメ | 色の名前 英語つき
- **タグ例**: 知育, 色, いろ, 幼児, 赤ちゃん, 2歳, 3歳, くだもの, 英語, colors for kids
- **説明欄**（ライセンスで表記が必要なクレジット）:

  ```
  ぴよちゃんと いっしょに、くだものの いろを あてよう！
  あか・オレンジ・きいろ・みどり・あお・むらさき・ピンク の7色を、日本語と英語で おぼえられます。
  ```
