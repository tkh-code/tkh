# TECTONICA INC. ホームページ（試作）

株式会社テクトニカの新しいホームページの試作です。構造図をモチーフにしています。

## 起動

```
cd homepage
python -m http.server 8000
```

`http://localhost:8000/` を開きます。`index.html` を直接開いても表示できます。

## 構成

- 通り芯ナビ：X1〜X6 の符号でセクションを移動します。
- ヒーローの架構は、ブラウザ内の骨組解析（3 次元の剛性マトリクス法）で動きます。平面 7 種（樹状柱・アーチ・張弦梁・トラス・吊り構造・片持ち・ラーメン）と空間 3 種（ラチスドーム・立体トラス・HPシェル）を切り替えられます。
  - 鉛直荷重 P：カーソルの位置に P=100kN がかかり、M・Q・N 図と変形をその場で描きます。節点をドラッグすると、その点を引っぱるのに必要な力 F を表示します。
  - 地震力 Q：水平力で左右に揺らします。
  - 固有振動：固有値解析（部分空間法）で 1〜4 次モードと固有周期を出します。クリックで次のモードへ。
  - 壊してみる：クリックした点の荷重を増やし、検定比（N/(A·Fy)+M/(Z·Fy)、Fy=235N/mm²）が 1 を超えた部材から破断させて組み直します。不安定になった荷重を崩壊荷重 Pu として表示します。部材断面は仮定値で、実際の設計値ではありません。
  - ✎ 描いてみる：1m グリッドに部材を線で引くと、その場で解き直します。GL 上の点は固定端。地面につながっていない架構は「不安定」と表示します。描いた架構も揺らす・固有振動・壊してみるが使えます。
- 揺らす（ヘッダー右上）：このページの 9 つのセクションを 1 層ずつとみなした 9 層のせん断型モデルに、模擬地震波（乱数から作成、最大 350 gal）を入力して時刻歴応答を求め、各セクションを各階の変位どおりに動かします（変位は拡大表示、層間変形角は傾きとして表示）。
  - 耐震構造：1 次周期 1.0 秒、減衰 3%。免震構造：最下層に周期 4 秒・減衰 20% の免震層を足したもの（減衰はモードごとに与えた近似）。
  - 下のパネルに、建物の揺れ・各層の最大層間変形角（1/100 の目安線つき）・地震波・屋上の変位を描きます。
  - 質量・剛性はセクションの高さから仮に決めた値で、実在の建物ではありません。
- 部材リスト：プロジェクト一覧を検索・地域で絞り込めます。◉ 印は写真付きです。
- 掲載数の分布荷重図：年ごとの雑誌掲載件数を、梁にかかる分布荷重として描きます。
- 表題欄：フッターは図面の表題欄の形です。
- 青図モード：右上のボタンで青焼き図面風の配色に切り替えられます。

## データの出どころ

- `data.js`：Drive の「HPプロジェクト管理シート」（list シートで HP掲載が ○ の行）と「TECTONICA INC. WEB」（publication / awards シート）から作成。
- `img/`：Drive「02.プロジェクト写真/0000_HP（縮小済）」の写真を 1600px 以内に縮小したもの。
